# バーチャルゲームセンター（Virtual Arcade）

ブラウザから入れる、クオータービュー（斜め見下ろし）のバーチャルなゲームセンターです。自分のキャラクターで店内を歩き、チャットとエモーションでやりとりし、
ゲームの筐体に YouTube の配信 URL と宣伝を設定して「どこで何が配信されているか」を店内を歩いて見て回れます。
クレーンゲーム・スロットマシン・2048 と Columns like game（コラムス風の落ち物パズル）と Hextris のゲーム筐体とスコアランキング・ほかの人のプレイの観戦・大会やイベントのポスターを貼る掲示板・コミュニケーションノート・機能追加要望箱・店内の BGM もあります。PC とスマホの両方で遊べます。

- 作り：Node.js 22.13 以降（`node:sqlite`）・Express・WebSocket（`ws`）・SQLite・React + Vite・Canvas 2D（TypeScript、npm workspaces）
- すぐ試す：

  ```bash
  npm install
  npm run build
  npm start          # http://127.0.0.1:8791/ を開く
  ```

- 自分のサーバ（Apache のリバースプロキシの下）に置く手順：[deploy/INSTRUCTIONS.md](deploy/INSTRUCTIONS.md)
- 仕様：[docs/DESIGN.md](docs/DESIGN.md)
- ライセンス：**MIT**（[LICENSE](LICENSE)）。**ただし `client/public/games/hextris/` のフォルダだけは GNU GPL v3**（Hextris を別のプログラムとして同梱。ソースはそのフォルダの JS がそのまま。
  店の本体とは postMessage でやりとりするだけで、本体に GPL のコードは入っていません）。店内の BGM の曲のファイルはリポジトリに入っていません（[data/bgm/README.md](data/bgm/README.md)。曲が無くても合成のオリジナル曲が流れます）。
  同梱している第三者のもの（2048・字体 Clear Sans・columns・字体 Laila・Hextris）は下の「[同梱している第三者のもの](#同梱している第三者のもの)」。

## バーチャルゲームセンター v0.7.0

ブラウザから入れる、クオータービューのバーチャルなゲームセンター。自分のキャラクターを歩かせ、チャットとエモーションでやりとりする。
ゲームの筐体（16 台）には YouTube の配信 URL と宣伝（イベント名・ゲーム名・プレイヤー名・備考）を設定でき、どこで何が配信されているかが店内を歩いて分かる。
店内には BGM が流れます（v0.2.0）。店の端のクレーンゲームでトランプのマークのバッジを取ったり、掲示板に大会・イベントのポスターを貼ったり、自分の発言を 1 つピン止めしたりできます（v0.3.0）。入口の近くのコミュニケーションノートにひとこと書いたり、要望箱から管理者に要望を送ったりもできます（v0.4.0）。
いつもの店（オープン部屋）のほかに、時間を予約して合言葉で入る**予約部屋**を 1 つ立てられます（v0.5.0）。
**2048** と **Columns like game**（コラムス風の落ち物パズル）と **Hextris** のゲーム筐体で遊べて、点数は店内の左の壁のポスターと窓の**ランキング**に残ります。同じ部屋の人のプレイを**観戦**することもできます。エモーションに**ベガ立ち**（動くまで腕を組む）も足しました（v0.6.0）。
**スロットマシン**で目押しに挑戦できます。クレーンゲームで取ったマーク 1 つがコイン 10 枚になり、残したいコインは預けて 4 文字のキーで引き出せます（v0.7.0）。
Web アプリ（PC・1920×1080 向け。**v0.4.0 からスマホのレイアウト**もあり、スマホで開くと自動で切り替わる）。自分のサーバの `/arcade/` などのパスに置ける（例 `https://example.com/arcade/`）。仕様は [docs/DESIGN.md](docs/DESIGN.md)。

## 起動（自分の PC で）

Node.js 22.13 以降（組み込みの `node:sqlite` を使うため）。

```powershell
# リポジトリのフォルダで
npm install
npm run build      # 型チェック + クライアントのビルド
npm start          # http://127.0.0.1:8791/
```

- 環境変数: `PORT`（既定 8791）・`HOST`（既定 127.0.0.1。LAN の別の機械から開くなら `0.0.0.0`）・`BASE_PATH`（例 `/arcade`。空ならルート）・
  `DB_PATH`（既定 `data/virtual_arcade.db`）・`MAX_PLAYERS`（同時に店内にいられる人数。50）・`CABINET_TTL_HOURS`（筐体が最後の更新から空きに戻るまで。6）・
  `ADMIN_PASS_HASH`（管理者の合言葉のハッシュ。下）・`ADMIN_TTL_HOURS`（管理者が続く時間。12）・`TRUST_PROXY`（`loopback` / `none`）・
  `BGM_DIR`（店内の BGM の曲の置き場所。既定 `data/bgm`）。
  v0.3.0 から：`CRANE_COOLDOWN_SEC`（クレーンゲームの 1 回ごとの待ち時間。20）・`CRANE_MAX_CHANCE`（ぴったりのときに取れる確率 %。65）・
  `BADGE_MODE`（`unique` = 4 種類を 1 つずつ（既定）/ `stack` = 同じものも重ねて持てる）・`BADGE_STACK_MAX`（stack のときの上限。3）・
  `BADGE_KEEP_MIN`（接続が切れてからバッジ・ピン止めが消えるまで。30）・`POSTER_WHO`（`all` = 全員が貼れる（既定）/ `admin` = 管理者だけ）・
  `POSTER_MAX_PER_USER`（1 人が同時に貼れる枚数。2）・`POSTER_MAX_TOTAL`（店全体の枚数。40）。
  v0.4.0 から：`NOTE_MAX_TOTAL`（ノートに残す件数。2000）・`REQUEST_MAX_TOTAL`（要望を残す件数。1000）。
  v0.5.1 から：`CHAT_TTL_HOURS`（チャットの発言を残す時間。24。過ぎた発言は DB からも開いている画面からも消える）。
  v0.7.0 から：`CABINET_MAX_PER_USER`（1 人が配信を登録できる筐体の数。4。1〜16）・`SLOT_BIG_ODDS`・`SLOT_REG_ODDS`（スロットの BIG・REG の確率 1/n。256・400。画面の確認用で、本番では設定しない）。
  `BASE_PATH` はビルドし直さずに変えられます（サーバが index.html に `<base href>` を差し込む）。
- PowerShell では `$env:BASE_PATH='/arcade'; $env:PORT='8798'; npm start` のように渡す（Git Bash で `BASE_PATH=/arcade` と書くと Windows のパスに書き換えられて起動しない）。
- 管理者の合言葉: `npm run hash-admin`（合言葉を聞かれる。画面には出ない）で `scrypt:…` の 1 行ができるので、それを `ADMIN_PASS_HASH` に入れて起動する。
  合言葉そのものはどこにも保存しない。長いもの（20 文字以上）をすすめる。設定しなければ管理者なしで動く。
- 開発: `npm run dev`（Vite http://localhost:5174/ + サーバ :8791。API と WebSocket は Vite がサーバへ中継）
- テスト: `npm test`（スマホのカメラ（追従・ピンチ・ドラッグ・画面の座標 ⇄ 床の座標）・レイアウトの切り替え・ノートの検証とページ分け・要望（管理者だけが読める）・クレーンゲームの確率と判定・待ち時間・バッジの付き方と消え方・ポスターの検証と期限と並び順・チャットのピン止め・BGM の音符データ・曲の一覧・視聴画面と BGM の判断・BGM のファイルの配信（拡張子の限定・パスの抜け道）・経路探索・YouTube の URL・NG 語・筐体の持ち主の決まり・入室と再入室・移動の検証・チャットの制限・筐体の操作・管理者・退室と入室の停止・
  BASE_PATH 付きの API と WebSocket・上限の人数など）

## 公開サーバに置く

```powershell
npm run package    # release/virtual-arcade-<版>.tar.gz と .sha256
```

tar の中身はそのまま動く形（`node server.js`）。サーバでは `npm install` も `tsx` も要りません。
手順は [deploy/INSTRUCTIONS.md](deploy/INSTRUCTIONS.md)（サーバに置く手順書。サーバ上の Claude Code にそのまま渡すこともできる）、
systemd は [deploy/virtual-arcade.service](deploy/virtual-arcade.service)、Apache は [deploy/apache-arcade.inc](deploy/apache-arcade.inc)。

## 遊び方

1. **入店**：名前（20 文字まで）と、体の色（8 種）・帽子や髪（6 種）を選んで［入店する］。アカウント登録はなく、このブラウザに保存した鍵で同じ人として戻れます
   （再読み込みしても同じ人・同じ場所。別のブラウザ・端末では別の人）。右上の名前から、あとで名前と見た目を変えられます。
2. **歩く**：床をクリックするとそこまで歩きます（筐体・壁は通れないので回り込む）。WASD・矢印キーでも歩けます（W = 画面の上）。
3. **チャット**：右の欄から発言（200 文字まで）。店内全体に届き、発言した人の頭上に吹き出しが数秒出ます。
   自分の発言の行にカーソルを置くと［📌］が出て、押すとその発言を**ピン止め**できます（1 人 1 つ。別の発言を押すと差し替え、もう一度押すと外れる）。
   ピン止めした発言は頭上の吹き出し（黄色い紙・ピンの印）として出しっぱなしになり、ほかの人にも見えます。
4. **エモーション**：下のボタン（👍 😂 😮 👏 ❤️ 👋 🎉 🔥）で、頭上に大きな絵文字が出ます。
   9 個目の腕組みのボタンは**ベガ立ち**（v0.6.0）：胸の前で腕を組んで立ち、頭上に腕組みの印が出ます。歩く・座る・ゲームを始めるまで続き、もう一度押すと外れます。
5. **筐体を使う**：空いている筐体の近く（2 マス以内）まで行ってクリック →［この筐体を使う］で持ち主になり、YouTube の URL
   （`youtube.com/watch?v=…`・`youtu.be/…`・`youtube.com/live/…`）と宣伝を設定できます。配信を登録できるのは 1 人 4 台まで（v0.7.0。サーバの `CABINET_MAX_PER_USER` で変えられます。部屋ごとに数えます）。
   持ち主はいつでも変更・［空ける］ができ、最後の更新から 6 時間で自動で空きに戻ります。
6. **配信を見る**：配信中の筐体は画面にサムネイルと「LIVE」の札が出て光ります。近づくかカーソルを置くと宣伝の全文が出て、
   いちばん近い配信中の筐体の 2 マス以内に入ると、その筐体の上に小さな埋め込み（音なし）が流れます。
   筐体をクリックすると［この中で視聴する］（大きなプレイヤー＋宣伝。チャットは右のまま。店内では筐体の前に座った姿になる）か
   ［YouTube で開く（新しいタブ）］を選べます。
7. **壁の大画面**：配信中の筐体の一覧を数秒ごとに切り替えて映し、下に管理者のお知らせが流れます。クリックすると一覧が開き、
   ［歩いて行く］か［視聴する］を選べます。
8. **管理者**：右上の［管理者］から合言葉を入れると管理者になります。どの筐体も変更・解除（筐体の窓から）、お知らせ（大画面とチャット）、
   チャットの発言の削除（欄の ×）、人を退室させる・その人の入室を一定時間止める、ができます。お知らせが出ると短いチャイムが鳴ります（BGM を消音にしていれば鳴らない）。
9. **クレーンゲーム**：右奥のクレーンゲームをクリック（遠ければ前まで歩いてから窓が開きます）。［→］を押している間アームが右へ、
   離すと止まり、次に［↑］を押している間奥へ。［下ろす］でアームが下りてカプセルをつかみ、出口へ運びます（途中で落ちることも）。
   キーボードは → / ↑ / スペース。カプセルの中身は **♠ ♡ ♦ ♧ のバッジ**で、取ると**退店するまで名前の後ろ**に付きます（例「たいよう♠♦」。
   頭上の名前・チャット・一覧など）。4 種類を 1 つずつ集めて、そろうとコンプリート。1 回ごとに 20 秒の待ち時間があります。
   当たり外れはサーバが決めます（アームがカプセルの真ん中にぴったりなら 65%、ずれるほど下がる）。
   バッジは再読み込みでは残り、上のバーの［退店］か、接続が切れてから 30 分で消えます（サーバを起動し直しても消えます）。
10. **ポスター欄（掲示板）**：左の壁の掲示板をクリックすると、大会・参加型対戦・イベントのポスターの一覧が開きます（固定したもの → 日時の近い順）。
   ［＋ ポスターを書く］で題名（40 文字）・種類・開始の日時（必須）・終了の日時・ゲーム名・内容（400 文字）・URL（http(s)）を書いて貼れます（1 人 2 枚まで）。
   書いた人は直す・はがすができ、開始（終了があれば終了）から 1 日で自動ではがれます。貼るとチャットに案内が流れ、壁の大画面にも「近日のイベント」として流れます。
   管理者はどのポスターもはがせ、先頭に固定できます。
11. **店内の BGM**：入店のボタンを押すと流れ始めます（再読み込みで入ったときは、最初のクリックかキー入力から。それまで下のバーに「🔇 クリックで BGM」）。
   下のバーの左に［🔈/🔇］・音量（既定 25%）・曲名（クリックで曲の一覧）・［次の曲］。設定はこのブラウザに残ります。
   `data/bgm/` に曲を置いていればそれを順番に流し（作者のサーバでは魔王魂の 5 曲）、一覧からはブラウザの中で合成するオリジナル 3 曲（ネオン・スタート／ミッドナイト・ロビー／トーナメント・ファイア）も選べます。
   視聴画面で動画が始まると BGM は小さくなって止まり、店内に戻ると流れます（近くの筐体の小さな配信は今までどおり音なし）。
12. **コミュニケーションノート**：入口の近くの机の上のノートをクリック（遠ければ前まで歩いてから開きます）。見開きの本の形で、
   1 ページに 4 件・開くといちばん新しいページ。［‹］［›］・← → キー（スマホは左右のスワイプ）でめくれます。
   ［✎ 書く］で名前（既定は自分の名前。書き換えてよい）とひとこと（3 行・90 文字まで）を書けます（1 人 10 分に 3 件まで）。
   書いた人は自分の分を、管理者はどれでも消せます。だれかが書くと、開いているノートにもその場で加わります。
13. **機能追加要望箱**：右の手前の赤い箱をクリックすると「要望を送る」窓。種類（新しい機能 / 不具合 / そのほか）・要望（500 文字まで）・名前（出さないこともできる）を送れます。
   **送った内容は管理者だけが読めます**（送った人にも後からは見えない）。管理者は［管理者］の窓の「📮 要望」のタブで、一覧・既読 / 対応済みの印・削除。
   未読の件数は［管理者］のボタンに出て、新しく届くと店内にいる管理者にだけ小さく知らせます。

14. **予約部屋**（v0.5.0）：奥の右の壁ぎわに予約部屋の扉と、予約カレンダーがあります。カレンダーをクリックすると予約表（PC は 7 日 × 30 分の表、スマホは日ごとの枠の一覧）。
   **空いている枠を押すと予約**できます（30 分単位・14 日先まで・1 人あわせて 5 時間まで。部屋名・予約する人の名前・説明・合言葉。時刻は日本時間）。
   予約の時間になったら扉をクリックして合言葉を入れると予約部屋へ（予約した人と管理者は合言葉なし）。入店の画面からも予約表を開いて予約したり、合言葉でそのまま予約部屋に入ったりできます。
   予約部屋はレイアウトは同じで色が違い、チャット・筐体・大画面・お知らせ・クレーンゲームは部屋ごと（ノート・要望箱・ポスター・BGM・バッジは共通）。
   終わる 10 分前・5 分前に案内があり、時間が終わると中の人はオープン部屋に戻って、予約部屋のチャット・筐体は消えます（予約部屋のチャットは保存しません）。
   予約した人・管理者は予約表（管理者は［管理者］の「🔑 予約」）から取り消せます。
   予約した人は、予約の時間の間、予約部屋の**主催**（名前に「［主催］」）として［🛠 部屋の管理］から、お知らせ・発言の削除・筐体を空ける・人をオープン部屋へ戻す（その予約の間は入れない）・
   合言葉を変える・早めに終える、ができます（サイトの管理者の操作はできません）。予約部屋の上には、いまの時刻と予約の残り時間（10 分・5 分で色が変わる）が出ます。
   ※ v0.5.0 から、このタブで店内にいたとき（再読み込み）だけ自動で入り直し、新しく開いたときは入店の画面が出ます（名前と見た目は入っています）。

15. **ゲーム筐体と 2048**（v0.6.0）：配信用の筐体の列の右端の隣に、金色の「2048」の看板の筐体があります。クリックすると（遠ければ前まで歩いてから）2048 の窓が開きます。
   矢印キー（WASD）で遊び、スマホは盤の上をスワイプ。ゲームオーバー・［New Game］・窓を閉じる・退店のときに、その点数を**記録**します（途中でやめてもそこまでの点数）。
   点数は、サーバが渡した乱数の種と手順をサーバがなぞり直して決めます（画面の点数をそのまま信じるのではないので、点数の書き換えはできません）。
   遊んでいる人は頭上の名前の横に 🎮 が出ます。1 台を何人で同時に使ってもかまいません。
16. **ランキング**（v0.6.0）：左の壁の奥（掲示板の右隣）に貼ったポスター（2048・Columns like game・Hextris の 3 枚）に総合の上位 5 人。クリック（遠くても歩かずに）か、2048 の窓の［🏆 ランキング］で、
   **総合**・**今月**（日本時間の月）の上位 50 人と自分の順位。1 人 1 行（いちばん良い記録）、同じ点数は先に出した人が上。
   自己ベストで総合 10 位以内か今月 3 位以内に入ると、チャットに案内が流れます。管理者は不適切な名前の記録を 1 行ずつ消せます。
   ランキングの窓は上のタブでゲーム（2048 / Columns like game / Hextris）を切り替えます。
17. **Columns like game**（v0.6.0）：配信用の筐体の手前の列の右端（16 番）の隣に、紫の「COLUMNS LIKE」の看板の筐体があります（ランキングは左の壁の 2 枚目のポスター）。
   縦 3 つの宝石を落として、同じ色を縦・横・斜めに 3 つ以上そろえて消す落ち物パズルです。窓の中の［Play］で始まり、← → で動かす・↑ で色を回す・↓ で速く・スペースで落とす・Enter で一時停止
   （スマホは下の Left / Swap / Drop / Right のボタン）。窓の外をクリックすると一時停止します。
   ランキングに載るのは Options が Standard・Colors 5・Height 0 のときです（開始の Level は自由。ランキングに開始レベルも出ます）。ほかの設定は練習（記録しません）。
   点数は、サーバが渡した種と「どのピースをどの列に何回回して置いたか」の記録をサーバがなぞり直して決めます（ゲームオーバー・Reset・窓を閉じる・退店のときに記録。途中でやめてもそこまでの点数）。
18. **Hextris**（v0.6.0）：2048 の筐体の右隣に、青い「HEXTRIS」の看板の筐体があります（ランキングは左の壁の 3 枚目のポスター）。
   真ん中の六角形を回して、外から寄ってくる色のブロックを受け止め、同じ色を 3 つ以上つなげて消すパズルです。窓の中の Play（クリック・Enter）で始まり、← → で回す・↓ で速く・P で一時停止
   （スマホは画面の左右をタップ）。ゲームオーバー・やり直し・窓を閉じる・退店のときに記録します。
   **Hextris の記録はブラウザの申告です**：時間で動くゲームなので、2048・Columns のようにサーバがなぞり直すことはせず、「消した数とコンボの倍率の記録が点数と合うか」「始めてからの時間に対して点数が増えすぎていないか」だけを確かめます。
19. **観戦**（v0.6.0）：だれかが遊んでいるゲーム筐体をクリックすると［▶ 遊ぶ］と［👀 〇〇 さんのプレイを見る］が出ます（頭上の 🎮 の名札をクリックしても見られます。同じ部屋の人だけ）。
   2048 は同じ盤を「見るだけ」で、Columns like game・Hextris は画面を縮めた画像（1 秒に 5 枚まで・保存しません）で見られます。
   遊んでいる人の窓には「👀 n 人が見ています」と［観戦を許可］のスイッチ（切ると見られません）。遊ぶ人が窓を閉じる・歩く・部屋を移ると「〇〇 さんのゲームが終わりました（点数）」。
   サーバの環境変数 `SPECTATE=off` で観戦をまるごと止められます（`SPECTATE_MAX_VIEWERS`・`SPECTATE_FPS`・`SPECTATE_MAX_STREAMS` で上限）。
20. **スロットマシン**（v0.7.0）：自販機の手前に赤い「SLOT」の台が 3 台。クリックすると（遠ければ前まで歩いてから）窓が開きます。
   **コイン**はクレーンゲームで取ったマーク 1 つ = 10 枚に両替（窓の「マークを両替」。マークはなくなります）。1 回 3 枚で、［レバー］（スペース / Enter）で回し、［左］［中］［右］（← ↓ →、Z X C。どの順でも）で止めます。
   リールは押した所から最大 4 コマすべって止まります。ベル・リプレイはどこで押しても揃いますが、7・BAR・スイカ・チェリーは狙わないと取りこぼします（目押し）。
   配当：7・7・7（BIG BONUS）250 枚・7・7・BAR（REG BONUS）100 枚・スイカ 10 枚・ベル 8 枚・チェリー（左の中段）2 枚・リプレイ（次の 1 回を掛けずに）。
   ボーナスが当たっているとリールが止まったあと **LUCKY ランプ**が光ります（揃えるまで続きます。7 を狙いましょう）。揃えるとチャットに案内。
   コインは自分だけに見えます（窓・上のバーの名前の後ろ・スマホのメニュー）。手元のコインはバッジと同じく退店すると消えます。
   残したいときは［🏦 コインを預ける］で全部預けると**アルファベット 4 文字のキー**が出ます（メモしてください。180 日まで・1 回だけ）。キーを入れて［コインを引き出す］で戻ります（別のブラウザからでも）。
   退店するときに手元にコインがあれば［預けてから退店］を選べます。

### スマホで遊ぶ（v0.4.0）

スマホ（幅 900px 未満・指で操作する端末で短い辺 600px 未満・スマホのブラウザ）で開くと、スマホのレイアウトになります（`?layout=pc` で PC の表示、`?layout=mobile` でスマホの表示を強制）。

- **縦向き**：上に細いヘッダ（店内の人数・配信中の台数・☰ メニュー）、真ん中に店内、下にエモーション・チャットの最新 3 行・発言欄。
  チャットの数行をタップ（か上へスワイプ）すると履歴のシート（自分の発言の 📌・管理者の ×）。メニューに予約表・予約部屋（v0.5.0）・BGM・見た目を変える・管理者・退店・操作の説明。
- **横向き**：店内を左に大きく、右の細い欄にヘッダ・エモーション・チャット。［›］でたたむと店内がもっと広くなる（［💬］で開く）。

## 店内の BGM について

- **このリポジトリには曲のファイル（音声）も一覧 `data/bgm/bgm.json` も入っていません。** 曲が無いときは下の合成の曲だけが流れます。
  一覧の書き方の例は `data/bgm/bgm.example.json`（`bgm.json` に写して使う。無くても、置いた音声ファイルが「ファイル名 = 曲名」の曲になる）。
- 作者のサーバでは **音楽：魔王魂**（https://maou.audio/ 。アコースティック02 / 11 / 46 / 50 / 52）を流しています。ループのための切り出し・つなぎ目の重ね・再エンコード・音量の調整のため編集しています
  （画面にも「音楽：魔王魂（ループ・音量の調整のため編集）」と出します）。
  **曲単体の再配布は規約で禁止**なので、曲のファイル（元の mp3 = `bgm/`、加工した ogg = `data/bgm/*.ogg`）は git に入れず、公開リポジトリ・公開ページにも置きません。
  `npm run package` の tar（自分のサーバに置くもの）には `data/bgm/` の音声ファイルと一覧 `bgm.json` だけが入ります。
- **合成の曲**はこのアプリのために作曲したオリジナル（ブラウザの Web Audio で演奏。データは `shared/src/songs.ts`）。
- 曲のループと音量は `tools/bgm/loop_bgm.py`・`loudness.py` で作れます。手順・`bgm.json` の書き方は [data/bgm/README.md](data/bgm/README.md)。
- **自分の曲を足すこともできます**（`data/bgm/` に mp3 / ogg / m4a を置く）が、**ファイルの権利は置く人の責任**です（店に入った人全員に配信されます）。
  自分で作った曲か、ウェブでの公開での利用が許諾された曲だけにしてください。
